# 生徒指名ランダムルーレット

教育実習や授業で使える、生徒をランダムに指名するためのシンプルなWebアプリケーションです。出席番号などを指定して、画面上でドラムロール演出を交えながらランダムな数字を大きく表示します。

## 特徴
- クラスの人数（$N$ 番まで）を画面から自由に指定可能
- 教室の後ろからでも見やすい、大きくてシンプルな数字表示
- ドラムロール風のシャッフル演出付き

## ファイル構成
- `index.html` : 画面の骨組み・入力欄
- `style.css`  : 見た目・アニメーション
- `script.js`  : ランダム抽選・演出の処理

## 使い方
1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザ（Google Chrome, Microsoft Edge等）にドラッグ＆ドロップして開きます。
3. クラスの人数を入力し、「指名する」ボタンをクリックするとルーレットが回ります。
